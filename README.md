## Overview

**TrainingLab** is an open-source project for building focused, repeatable training experiences on dedicated **Counter-Strike 2** servers. Instead of bundling unrelated practice tools into one monolithic game mode, it provides a shared foundation for independent training modes, player sessions and server lifecycle management.

The first focus is **NADR**, a grenade-practice mode designed around reliable practice environments, map markers and, eventually, lineup workflows, trajectory visualization and replay tools.

> [!IMPORTANT]
> **Early development preview.** The architecture is being implemented and NADR is under active development. TrainingLab is **not yet a production-ready release**. Features shown as planned below are goals, not promises of functionality available today.
